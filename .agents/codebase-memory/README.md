# Ski Codebase Memory Index

This directory provides access to the knowledge graph and structural index of **Ski** generated by [codebase-memory-mcp](https://github.com/DeusData/codebase-memory-mcp).

## Project Details

- **Project Identifier**: `home-ilyamiro-Projects-Ski`
- **Indexed Language**: Rust, Nix, Markdown, TOML
- **Direct CLI Wrapper**: `.agents/bin/cbm`

## Files in this Directory

| File | Description |
|------|-------------|
| `ski.db` | Symlink to active SQLite knowledge graph (`~/.cache/codebase-memory-mcp/home-ilyamiro-Projects-Ski.db`) |
| `graph.db.zst` | Compressed persistent knowledge graph artifact |
| `artifact.json` | Metadata and checksums for the persistent artifact |

## Quick Usage

### Via Helper Script (`.agents/bin/cbm`)

A preconfigured CLI wrapper is available at `.agents/bin/cbm`:

```bash
# Architecture summary
.agents/bin/cbm get_architecture

# Search symbols (functions, structs, variables, modules)
.agents/bin/cbm search_graph --name-pattern ".*"

# Trace function call chains (inbound/outbound)
.agents/bin/cbm trace_path --function-name "read_directory" --direction both

# Retrieve code snippet by qualified name
.agents/bin/cbm get_code_snippet --qualified-name "home-ilyamiro-Projects-Ski.src.app.SkiApp.new"

# File outline
.agents/bin/cbm get_file_outline --file-path "src/app.rs"

# Query with Cypher
.agents/bin/cbm query_graph --query "MATCH (n:Function) RETURN n.name, n.file_path LIMIT 10"

# Re-index the codebase after changes
.agents/bin/cbm reindex
```
