# Ski Codebase Memory Skill

This skill provides fast code intelligence and structural navigation across the **Ski** codebase using the pre-indexed knowledge graph generated by `codebase-memory-mcp`.

---

## 1. Quick Capabilities

The codebase memory knowledge graph contains:
- **Project**: `home-ilyamiro-Projects-Ski`
- **Direct CLI Wrapper**: `.agents/bin/cbm`
- **MCP Server Binary**: `.agents/bin/codebase-memory-mcp` or `~/.local/bin/codebase-memory-mcp`

---

## 2. Usage Reference via `.agents/bin/cbm`

```bash
# Architecture summary
.agents/bin/cbm get_architecture

# Search symbols (functions, structs, modules)
.agents/bin/cbm search_graph --name-pattern ".*"

# Trace call chains
.agents/bin/cbm trace_path --function-name "<func>" --direction both

# Retrieve code snippets
.agents/bin/cbm get_code_snippet --qualified-name "<symbol>"

# Run Cypher queries
.agents/bin/cbm query_graph --query "MATCH (n:Function) RETURN n.name LIMIT 10"

# Re-index after modifying code
.agents/bin/cbm reindex
```
